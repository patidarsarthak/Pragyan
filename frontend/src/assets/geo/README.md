# Map Geometry

Boundary geometries utilized by the SIH26074 Panchayat Weather Intelligence Platform.

- District outlines: Simplified TopoJSON conforming to Survey of India standards and Local Government Directory (LGD) administrative codes.
- Panchayat polygons: LGD Gram Panchayat spatial polygons served dynamically via vector tiles and GeoJSON for operational districts.
- Boundary Policy: Complies with the 2021 Indian Geospatial Data Guidelines.
