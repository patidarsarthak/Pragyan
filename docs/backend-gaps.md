### 2.2 Synthetic Target Generation: Exact File & Line Citations
As formally uncovered in [`data_pipeline/reports/LEAKAGE_AUDIT.md`](file:///c:/Users/LOQ/Desktop/sih26074/data_pipeline/reports/LEAKAGE_AUDIT.md), all fine-scale downscaled "ground-truth" targets in the wide dataset were generated by **deterministic mathematical formulas** applied to coarse inputs and static terrain features:

1. **Temperature Target (`TARGET_TEMPERATURE`):**
   - **Exact Code Location:** [`ml/src/dataset.py:94-98`](file:///c:/Users/LOQ/Desktop/sih26074/ml/src/dataset.py#L94-L98)
   ```python
   df["TARGET_TEMPERATURE"] = (
       df["COARSE_TEMPERATURE"] 
       - (df["ELEVATION_M"] - 200.0) * 0.0065 
       + np.where(df["LANDCOVER_CLASS"] == 13, 0.45, 0.0)
   ).round(2)
   ```
   - **Finding:** Purely algebraic hydrostatic lapse rate ($6.5\text{ }^\circ\text{C/km}$) + landcover constant. **Zero physical sensor ground truth.**
   - **Frontend Action:** The near-zero temperature scores ($MAE = 0.0022\text{ }^\circ\text{C}$, Pearson $r = 1.0000$) **must be hidden from headline Evidence cards**. The Evidence screen will display:  
     `"Not independent validation (target derived from the same lapse-rate formula)"`.

2. **Relative Humidity Target (`TARGET_HUMIDITY`):**
   - **Exact Code Location:** [`ml/src/dataset.py:101-104`](file:///c:/Users/LOQ/Desktop/sih26074/ml/src/dataset.py#L101-L104)
   ```python
   df["TARGET_HUMIDITY"] = np.clip(
       df["COARSE_HUMIDITY"] + (df["ELEVATION_M"] - 200.0) * 0.012, 
       5.0, 100.0
   ).round(2)
   ```
   - **Finding:** Pure linear transformation of elevation. **Zero sensor ground truth.**

3. **Rainfall Fine Target (`FINE_RAINFALL`):**
   - **Exact Code Location:** [`data/scripts/build_unified_dataset.py:192-193`](file:///c:/Users/LOQ/Desktop/sih26074/data/scripts/build_unified_dataset.py#L192-L193)
   ```python

   f_vals = [round(float(max(0.0, v * elev_factor + (0.05 if v > 0.5 else 0.0))), 3) for v in c_vals]
   ```
   - **Residual Rainfall Target:** [`ml/src/dataset.py:89-90`](file:///c:/Users/LOQ/Desktop/sih26074/ml/src/dataset.py#L89-L90):
   ```python
   df["TARGET_RESIDUAL_RAINFALL"] = df["FINE_RAINFALL"] - df["COARSE_RAINFALL"]
   ```
   - **Finding:** Despite metadata claiming "UCSB CHIRPS v2.0", the fine-scale rainfall target was synthesized by scaling coarse ERA5-Land rainfall by an elevation factor `1 + (elev - 200)/1000`.
   - **Frontend Action:** The Evidence tab must honestly state:  
     `"Evaluation performed against elevation-parameterized pseudo-targets; no in-situ rain gauge station validation exists in this dataset."`

4. **Evapotranspiration ($ET_0$) Target:**
   - **Exact Code Location:** [`ml/src/dataset.py:115-119`](file:///c:/Users/LOQ/Desktop/sih26074/ml/src/dataset.py#L115-L119)

### 4.2 Soil and Crop Defaults
- **Code Location:** [`backend/services.py:1910-1914`](file:///c:/Users/LOQ/Desktop/sih26074/backend/services.py#L1910-L1914)
  ```python
  field_capacity_mm = 140.0 # Field capacity in 60cm root zone
  wilting_point_mm = 65.0   # Permanent wilting point
  total_available_water_mm = field_capacity_mm - wilting_point_mm # 75 mm
  p_depletion_fraction = 0.50 # Management Allowed Depletion (MAD)
  ```
- **Finding:** A black Vertisol is physically inappropriate as a blanket profile for all of Dhanbad (which sits on Chota Nagpur crystalline gneisses and red-yellow sandy loams), and assuming paddy at $K_c = 1.15$ for every panchayat is an assumed default.
- **Frontend Action:** Dropped all claims of "ICAR soil profile". The UI explicitly labels this:  
  `"Assumed default soil profile (60 cm root zone: FC 140 mm, WP 65 mm, MAD 50%), not measured"`.

### 4.3 Uncertainty Hatching Mechanism
- **Code Location:** [`backend/services.py:1213-1227`](file:///c:/Users/LOQ/Desktop/sih26074/backend/services.py#L1213-L1227)
  ```python
  q75 = float(ci_widths.quantile(0.75))
  ...
  "is_high_uncertainty": bool(w >= q75)
  ```
- **Finding:** The backend does not use an arbitrary 40% threshold. It sets `is_high_uncertainty: true` when a Panchayat's 80% CI width ($w = p_{90} - p_{10}$) equals or exceeds the **75th percentile ($Q_{75}$)** of uncertainty widths across all Panchayats on that forecast day.
- **Frontend Action:** Ingest `is_high_uncertainty` directly from the API response (`/map/forecast-frames`).

### 4.4 Past Events (Replay) Missing Observed Values

  `mean_rain_mm`, `max_rain_mm`, `peak_gp_code`, `ci_lower_mm`, `ci_upper_mm`, `n_gps_over_50mm`, `narration`.
  It **lacks** `observed_rainfall_mm` and `coarse_baseline_mm`!
